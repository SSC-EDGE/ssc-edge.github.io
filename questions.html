How to use:
Upload an Excel .xlsx / .xls file or a .csv file. Each row becomes one question.

Required columns:
Subject, Chapter, Question English, Question Hindi, Option A English, Option A Hindi, Option B English, Option B Hindi, Option C English, Option C Hindi, Option D English, Option D Hindi, Correct

Optional columns: Explanation, Bonus, Video Link.

Subject and Chapter are matched automatically with your existing SSC EDGE Subject/Chapter records. You do not need to enter database IDs.

Important: Do not change the column names in the template.
